Method

Live model: N-HiTS, the architecture selected on pinball loss across 59 rolling-origin backtest folds, with conformally calibrated intervals. Its inputs are prices from auctions that have already cleared, calendar terms and the day-ahead load forecast. SMARD publishes the wind and solar forecasts only after the auction they would inform, so the live model cannot use them. Realised outturn is never used.

The research version, which also uses the wind and solar forecasts and so cannot run live, scored on a held-out year never used in development MAE 23.45 EUR/MWh against 18.88 in backtesting. Substituting realised inputs for published forecasts would improve it by 20%, which is what the gate-closure constraint costs.
